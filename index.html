GitHub 자동 저장 연결

GitHub Pages를 배포하는 저장소의 정보를 입력하세요. 파일은 같은 저장소의 같은 경로에 이미 있어야 합니다.

GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens에서 해당 저장소만 선택하고 Contents: Read and write 권한을 주세요. 토큰은 이 기기의 이 브라우저에 계속 보관되며 HTML·GitHub 저장소에는 포함되지 않습니다. 개인 기기에서 사용해 주세요. 관리자 로그인 시 자동 연결됩니다. 토큰 만료·권한 취소 또는 브라우저 데이터 삭제 시에는 다시 입력해야 합니다.

GitHub Pages의 배포 브랜치·폴더와 위 경로를 맞춰 주세요. 연결하면 저장소에 있는 최신 자료를 불러옵니다.
